# ⚙️ Setup

A mise bootstrap config that sets up my Mac.

[![Automation (xkcd)](https://imgs.xkcd.com/comics/automation.png)](https://xkcd.com/1319/)

## Installation

Install mise, then run the bootstrap task. `mise bootstrap` needs mise 2026.7.4 or
later — earlier versions gate it behind an experimental flag.

```shell
curl -fsSL https://mise.run | sh
mise bootstrap
```
